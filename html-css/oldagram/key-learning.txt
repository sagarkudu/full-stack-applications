2. Icon can feel shaky when hover

.icon-comment:hover {
  width: 22px;
  height: 22px;
}

transform: scale(1.1);

Note: 
1. The browser has to recalculate the layout because the element became bigger. That can push the other icons around, which looks like shaking/jumping.
2. Now the browser still considers the icon 20 × 20, but visually scales it to about 22 × 22.
